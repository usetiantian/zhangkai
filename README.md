# 水（SHUI）

水是一个独立、持续运行、连接真实世界的演化型自治认知系统。

它维护自己的身份、价值权重、目标、世界模型、记忆和能力；主动观察外部变化，形成可检验判断，规划并执行行动，根据真实结果学习，并通过版本化验证扩展自身能力。

## 当前状态

**Phase 0：架构与验证基线。尚无自治代码投入运行。**

项目进度与每一步证据见 [`PLAN.md`](PLAN.md)。

## 工程原则

1. **独立**：不 import、不复制、不依赖 Nexus 或工作区其他项目。
2. **标准库优先**：首期运行时只使用 Python 标准库；新增依赖必须有不可替代证据和决策记录。
3. **证据驱动**：参数、阈值和权重来自配置、观测或实验，不把拍脑袋常量藏在代码里。
4. **配置与代码分离**：可变化策略进入配置；代码只实现机制与不变量。
5. **真实闭环**：不以模型自述作为成功证据，只接受环境观测、测试和可复现结果。
6. **能力可插拔**：模型、数据源和工具都是适配器；认知内核不绑定供应商。
7. **广泛自治**：水在运行环境授予的范围内自主规划和执行，不要求逐次人工确认。
8. **可恢复**：有副作用的动作必须留下审计证据；可逆动作必须有恢复路径。
9. **不伪装进步**：不得通过修改测试、评价指标或删除失败记录提高成绩。
10. **一步一验**：阶段未通过验收，不进入下一阶段。

## 首个里程碑

```text

→ 保存原始证据、来源、时间和哈希
→ 检测变化
→ 更新结构化世界模型
→ 形成可检验事件
→ 运行确定性验证
→ 沉淀经验与审计记录
```
