# ADR-0002：模块直接位于项目根目录

- 状态：已接受
- 日期：2026-07-31

## 背景

`src/shui/` 布局适合需要打包发布的 Python 库，但水是独立运行的自治系统。双层同名目录增加路径长度和理解成本，没有已经观测到的发布需求。

## 决策

身份、感知、世界模型、认知、执行、学习和演化等模块直接位于 `C:/Users/87999/shui/`。配置、运行数据、文档和测试也位于同一项目根目录下各自独立的目录中。

## 考虑过的方案

- 保留 `src/shui/`：导入隔离更严格，但当前增加无收益的层级。
- 模块直接放根目录：结构直观、路径短，符合当前独立应用定位，因此采用。

## 结果

项目更容易理解和操作。如果未来出现可验证的打包发布需求，再通过新的 ADR 评估迁移，而不是提前设计。
