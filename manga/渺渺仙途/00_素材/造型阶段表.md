# 《渺渺仙途》造型阶段表

**作用**：人物一致性的核心。同一个角色跨集必须用同一张定妆图；只有剧情节点明确
"换装/换发型"时，才生成新造型，并**以旧定妆图为底图做图生图**，保证脸不变。

**机制**：
1. 每张定妆图 = 一个"造型版本"，文件名 `dingzhuang_<角色>_<版本号>.png`
2. `00_素材/当前造型.json` 记录每集该用哪个版本
3. 剧情跨过阶段边界时：
   ```bash
   python tools/manga_costume.py --base dingzhuang_林渺_00002.png --out dingzhuang_林渺_00003.png \
       --desc "改穿万象宗深青色内门道袍，束发玉冠，腰悬青色小葫芦"
   ```
   然后更新 `当前造型.json`。
4. 制作每集前，确认 `当前造型.json` 与该集所属阶段一致。

## 铁律

- **不许在同一集里换造型**。换装必须发生在集与集之间，且剧情上说得通。
- **脸永远不变**。换装只改服装、发型、配饰，用旧图做图生图。
- **年龄跟着剧情走**。林渺从16岁到元婴，跨越几十集，脸要有成长感，
  做法是换装 + 提示词里更新年龄描述（16岁 → 22岁 → 28岁），而不是换脸。
