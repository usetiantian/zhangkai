# 第01章 灶屋戏 改写对照（用对白模式库重做）

## 旧（流水：问—答—再解释，整场没有一件事发生）

　　天黑透，灶屋才点灯。灶膛火压得低，锅底映出一点红；柴捆靠在门后，灶台上扣着一只缺口碗，碗沿五枚铜锔钉，最后一枚偏出去半分，钉脚翘着。
　　姜氏用一截炭在碗沿画了一道，画完把碗扣回去，没抬头。陈禾拿柴拨火，火苗稳得像一条线，线头却一直往灶膛深处缩。
　　“哥，碗上那些痕是数什么，数到多少算完。”
　　“数日子还用画。”
　　陈满把手伸到火口上烤，疤被烤得发痒，像有细针在皮里走。他翻过手背，让火舌舔过指节。
　　“她数的是还能盛多少顿饭。”陈禾说，“哥你知道她数到哪天不数了吗。”

## 新（模式1 家常带压 + 模式6 先要好处 + 模式9 先共情再提要求）

　　天黑透，灶屋才点灯。灶膛火压得低，锅底映出一点红；柴捆靠在门后，灶台上扣着一只缺口碗，碗沿五枚铜锔钉，最后一枚偏出去半分，钉脚翘着。
　　姜氏用一截炭在碗沿画了一道，画完把碗扣回去，没抬头。陈禾拿柴拨火，火苗稳得像一条线，线头却一直往灶膛深处缩。
　　“哥，碗上那些痕是数什么，数到多少算完。”陈禾把火钳搁下，“娘一天画一道，我数过，三百二十八道。”
　　“数日子。”陈满把手从火口收回来，说。
　　“数日子还用画。”陈禾把柴往里送了送，火苗矮下半寸，“娘看的是碗，不是灶。哥，她数到哪天不数了，你知道吗。”
　　陈满没答。疤被烤得发痒，像有细针在皮里走。
　　姜氏把粥盛了三碗，野菜稀得照见人影，最稠的那碗放在陈满面前。“砖没了可以再找，釉没了能换。”陈满从怀里摸出那四只锔碗，一只只摆在灶台上，“这四只，值两斤半粮。”
　　“碗我要，粮我不要。”姜氏把碗推回去，“我要三斤半釉。”
　　“镇上换不来三斤半，只有两斤半的。”陈满说。
　　“那就换两斤半粮，再拿粮去换。”姜氏把炭放下，“粮我攒了两年，够换半斤。”
　　陈满看着那四只碗。灶膛里的火矮了半寸，娘脸上那道光跟着暗下去，“娘。”他说，“画到三百五十五道那天，娘等我出窑。”
　　姜氏收碗的手停了一下，又继续。她一句话没说，碗就摞成了三只。

## 改了什么

1. **这场戏原本没有事**。旧版是"陈禾问—陈满答—陈禾再解释"，问完就完了；
   而且我上一轮删台词时把"数日子。"误删了，问答还断了。
2. **陈满不再解释**。删掉"娘，三十六件四十二斤粮…"这类复述读者已知信息的台词，
   改成**把四只锔碗摆到灶台上**——他要什么，用动作说，不由嘴上讲。
3. **娘给条件，不给道理**（模式6 先要好处）："碗我要，粮我不要。我要三斤半釉。"
4. **娘最后还是那句最好的**（模式9 先共情再提要求）：
   "画到三百五十五道那天，娘等我出窑。"——她不给承诺，她给一个日子。
5. **压力靠沉默传递**（模式1 家常带压）：
   "陈满看着那四只碗。灶膛里的火矮了半寸，娘脸上那道光跟着暗下去。"——不写"他心里发凉"。
