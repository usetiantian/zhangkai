# 《渺渺仙途》漫剧制作规范（唯一事实源）

> 这份文件 + `定妆.txt` + `造型阶段表.md` + `当前造型.json` 构成全部制作约束。
> 任何一集开工前先读这四份，改剧情/改风格也先改这里。

## 一、风格（写进 global_prompt，且每个 Shot 前都要带）

**国产玄幻动漫**（《遮天》《完美世界》《仙逆》那一挂）：

    高饱和度厚涂上色，精细锐利描边，深邃明暗对比与体积光，人物边缘轮廓光，
    高饱和玄幻配色（暗金、青蓝、赤金、月白、紫电），画面带灵气粒子、法术光效、光晕；
    人物七点五头身写实比例，五官精致；远景有规模感的仙侠建筑、山峦云海、巨石古殿。

**禁止**（这些词一出现画面立刻回到 80 年代国产动画）：
平涂赛璐璐、暖黄复古色调、老电影质感、水墨晕染、颗粒感、复古滤镜、80年代动画感、
欧美卡通、日式少年漫、真人实拍、3D写实。

**禁止现代元素**：玻璃幕墙、水泥、电线杆、汽车、塑料、拉链、眼镜、现代灯具、衬衫西服。
古风场景里 H3 默认会塞这些东西，必须显式禁。

## 二、人物

### 年龄红线
成年角色一律成年体型：肩宽、身量够、手掌有骨感、喉结/锁骨可见、七到八头身。
**禁止把成年角色画成儿童**，禁止 Q 版幼态比例、圆脸包子脸。
只有林小雨是十二岁小姑娘。

### 发型红线（古风仙侠，不是现代理发店）
全片禁止：平头、寸头、板寸、短寸、齐耳短发、欧美发型、烫发。

| 角色 | 发型 |
|---|---|
| 林渺 | 黑色长发束成高马尾，深青/墨色发带扎紧，其余披散到肩背，鬓边留几缕碎发 |
| 苏禾 | 黑色长发盘成圆髻插银簪 |
| 王天霸 | 黑色高冠束发，暗金发饰 |
| 林守田 | 花白头发用灰色布巾束在脑后 |
| 林小雨 | 双丫髻扎红头绳 |
| 青葫道人 | 白须老者，长发束起 |

### 一致性三件套（缺一个就会漂）
1. **身份** → 角色定妆图（Qwen-Image 生成三视图），作为段的 `refs`，
   提示词里显式写 `<Subject N> is the character XXX defined by <Picture N>.`
2. **声音** → 克隆音色 mp3，作为段的 `voice_refs` + `voice_modes: {"xx.mp3": "voice"}`
   （voice 模式 = 只学音色，台词仍由提示词给；copy 模式才是对口型配音）
3. **服装** → 造型阶段表 + 当前造型.json。换装只发生在集与集之间，
   用旧定妆图做图生图换装，脸不变。

> 段里只要有 `voice_refs` 或 `refs`，插件自动切 Ref2VA 线路，不用手动改模式。

## 三、场景（每场都要写到）

必写五要素：**材质 / 层次 / 光源 / 氛围 / 规模感**。

- 材质：青砖灰瓦瓦片青黑有苔痕、木格窗糊半透油纸、木面有包浆、石面被绳索磨出凹槽、
  粗麻井绳、木桶箍铁圈、陶缸口覆荷叶、铜锁氧化发绿
- 层次：前景遮挡物 / 中景主体 / 远景背景，三层都要有
- 光源：写清方向、色温、明暗对比（窗纸透昏黄灯光、夕阳斜射光柱里有浮尘、
  灵光自下而上打亮面部、烛火跳动）
- 氛围：尘埃/雾气/灵气粒子/雨丝/落叶/香火烟气
- 规模感：门楣斗拱、层檐飞角、巨龙盘绕的石柱、远处云海翻涌、
  灵石矿脉、护山大阵光罩、万人广场

## 四、道具（点名 + 质感 + 状态）

不要写"一个葫芦"，要写"拇指大小的青色小葫芦，温润青玉质地，内部有细微荧光，
用旧红绳系着"。镜头里出现的道具都要有来历和磨损痕迹。

常用道具库（按需扩）：测灵玉（乳白半透明、内部流光游走、盘龙青石底座）、
青色仙葫、九霄剑（无鞘、剑身有裂纹）、玉符（羊脂玉、边缘焦黑）、
玄天令（青铜、兽面纹）、聚灵丹（朱红丹丸、丹香）、避火符（黄纸朱砂）、
储物袋（灰麻布、绣着万象宗徽记）、灵石（灰白晶体、内含絮状灵光）。

## 五、场面要燃（打斗/高潮）

**不要**只写"两人激战"。要拆成动作 + 加速度 + 冲击 + 特效 + 镜头运动。

写法的骨架：

    动作分解：起势 → 交锋 → 变招 → 决胜，逐个动作写清
    力量感：地面龟裂、砖屑飞溅、气浪把尘土推开、护体灵光被压出裂纹、
             山体震落碎石、衣袍被罡风撕开
    速度感：残影、剑光拖出长痕、身影化作流光、慢镜与快切交替
    特效：剑气纵横、灵光爆开、五色光环旋转压缩、符文亮起后炸成光屑、
           灵气漩涡、掌风凝成实体
    镜头：低机位贴地仰拍、快速推近到眼睛特写、环绕跟拍、冲击瞬间定格、
           慢动作拉出全景收尾
    声效：兵刃交击的金属爆鸣、骨骼闷响、灵力对撞的低频轰鸣、碎石落地

写法示例（不要照抄，按场景改写）：

    林渺脚掌猛踏青石，井台应声龟裂，泥水四溅。他腰间的青色仙葫骤然亮起，
    一道青光自葫口喷薄而出凝成半透明剑形；对面黑袍元婴双臂一振，黑色灵环炸开如墨莲倒卷，
    两人剑锋相击的刹那，青光与黑环同时崩碎成漫天光屑，气浪把整片青石街掀翻，
    尘土中只剩两道身影倒悬半空各自喘息。低机位贴地仰拍，冲击瞬间定格在两人交错的剑尖。

## 六、节奏与硬约束

| 约束 | 数值 |
|---|---|
| 每段时长 | ≤ 15 秒（超了模型会崩） |
| 每段台词 | 汉字数（含标点）≤ 该 Shot 秒数 × 4 |
| 单集总长 | 60–90 秒（6 段左右） |
| 分镜解析 | 30 秒分镜自动切成 3 段（实测 9.9/9.9/10.2） |
| 每镜动作数 | 1 个主要动作 + 1 个信息变化 + 1 个清晰结束状态 |
| 相邻镜头 | 至少改变四项：机位侧面/高度/景别/焦段/主体位置/前后景/运动方式/遮挡 |
| 每集重渲染成本 | 约 35 分钟 GPU |

## 六、台词 vs 内心暗想（必须分清）

| 类型 | 写法 | 是否进 `<d>` | 画面 |
|---|---|---|---|
| 说出口的台词 | `角色名：台词` | ✅ 进 `<d>[Chinese]…</d>` | 人物开口，有口型 |
| 内心独白 / 暗想 | `（内心独白）……` 或 `内心独白（闭口不开口）：……` | ❌ **不进 `<d>`** | 人物**闭口**，靠表情/眼神/手部动作演出 |
| 旁白 / 画外音 | `旁白（画面无人开口）：……` | ❌ **不进 `<d>`** | 画面无对口型说话的人 |

**为什么**：H3 的 `<d>` 标记 = 角色出声说话（带口型）。把暗想塞进 `<d>`，
模型会让角色张嘴把心里话说出来，完全错。

**规则**：
1. 分镜任务书里，暗想必须写成 `（内心独白）…` / `旁白（画面无人开口）：…`，
   和 `角色名：台词` 明确区分开。
2. 分镜阶段，AI 必须把内心独白留在镜头描述里（如"他闭口不言，眼神暗下"），
   **不得**转成 `<d>`。
3. `tools/manga_check.py` 会检查：如果 `<d>` 标签里出现内心独白/旁白标记就报错。
4. 确实要让心声出声（开篇钩子常用）：**单独做一段**——该段只有一条心声，
   配合段的 `audio` + `audio_src="ref"` + `audio_ref_mode="copy"`，
   用 Qwen3-TTS 生成的"心声/旁白音色"整轨替换，人物全程闭口。
   一段里同时有 spoken 台词和心声，当前插件不支持。

## 七、一集的标准工序

```bash
# 0) 确认本集属于哪个造型阶段，更新 00_素材/当前造型.json
# 1) 章节原文 -> 分镜任务书
python tools/guofeng_manga.py beat 章节.txt --duration 75 --context 00_素材/定妆.txt -o 01_分镜任务书.txt
# 2) 校验（时间轴连续 + 台词不超速）
python tools/manga_check.py 01_分镜任务书.txt
# 3) -> H3 官方三字段分镜（带自动重试修复）
python tools/manga_storyboard.py 01_分镜任务书.txt -o 02_官方分镜.txt     --context 00_素材/定妆.txt --ep "第X集 标题"
# 3b) AI 写的时长常超（75 秒写成 86~116 秒）-> 确定性重定时
python tools/manga_retime.py 02_官方分镜.txt --duration 75
# 3c) AI 漏写 director_import_manifest -> 补上
python tools/manga_manifest.py 02_官方分镜.txt --duration 75
# 4) -> 段表
node tools/h3_segments.mjs < in.json > 03_段表.json
# 5) -> Ref2VA 六字段 + 绑定定妆图
python tools/manga_postprocess.py 03_段表.json -o 03_段表_ref2va.json --ep "第X集 标题"
# 6) 组 API prompt，先校验再出片
python tools/wf2api.py "D:/.../导演台11.0.json" --check
python tools/guofeng_manga.py video 03_段表_ref2va.json
# 7) 合并整集 + 抽帧验收
python tools/manga_merge.py <project_id> <段数> 目标目录
```

**验收标准**：抽帧逐张看——脸对不对、年龄对不对、发型对不对、衣服对不对、
场景有没有现代元素、打斗有没有燃。任何一项不过就改提示词重渲该段。
