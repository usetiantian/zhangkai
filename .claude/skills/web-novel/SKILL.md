# 网文生产系统

代码在 `tools/novel/`，与具体书无关，换任何书都能用。完整说明见 `tools/novel/README.md`。

## 开新书（三步）

```bash
# 1) 空台账
python tools/novel/ledger.py 《书名》 <书目录> --protagonist 主角 --age 16 --origin 出身
# 2) 风格指南：拿参考书当标尺，实测指纹后生成目标带（可多本）
python tools/novel/style_guide.py <书目录> --ref 参考书.txt --ref2 参考书2.txt --name 书名
# 3) 逐章推进
python tools/novel/pipeline.py <书目录> --chapter 03 --source 章节03.txt --title 标题
```

流水线四步产物全部落盘，任一步不满意就只重跑那一步：

- `计划/第NN章_场次计划.md` —— 时间轴连续、每场一个动作、台词 ≤ 秒数×4
- `计划/第NN章_角色意图卡.md` —— 要什么/知道什么/情绪/怎么开口/**潜台词**
- `正文/第NN章_标题.md`
- `审稿/第NN章_审稿.md` —— 硬指标 + 重复检测 + 一致性 + S/A/B/C/D 评级

## 四条不能忘的规则

1. **风格指南是从参考书实测出来的**，不是凭感觉。指标不合就改提示词再生成，
   不要跟自己的"网文印象"较劲。
2. **对话不能像流水**。每场先写角色意图卡（尤其"潜台词"），再写正文。
   台词是完整的话（均 ≥18 字），不是"嗯。""好。"。
3. **段落是一段一个完整信息单元**（40–90 字），段间只用一个换行，
   每段开头两个全角空格，对白用中文引号。
4. **Reviewer 是门禁**：S/A 才进下一章，C 以下返工。

## 五、收敛到及格的做法（实测 25 轮得出的）

LLM 一次写不准数字，**必须靠"生成→测量→带反馈重写"的回路**，光改提示词没用。
`pipeline.py` 的 write 步已经内置这个回路（默认 4 轮，每轮把实测偏差翻译成具体指令）：

- 反馈要给**可执行的做法**，不要只说"太长了"。例如
  「你的句子太短（平均 22 字，要 26-32 字）。用逗号把两三个分句串成一句，
  照这个例子写：『壁里还留着余温，顺着指节上的旧烫疤往骨头里钻，钻到一半停住了。』」
- 反馈要**双向**：太长就说"压到 X 字，一句话讲一件事"，太短就给范例。
- 段落长和句子长是**同一个杠杆**：句长 26-32 + 每段 2 句 = 段长 52-60。
  只调一个另一个会塌。
- **标题必须确定性写死**：模型会从台账的进度表/伏笔表里抓错标题（实测把第1章写成"第3章 没风"）。
  写完强制改首行，并把进度表从上下文里剔掉。
- 目标带要用**参考书自己的四分位区间**（p25-p75），不是"均值 ±10%"。
  参照书单章长度的真实分布是 1714-4357，用均值±10% 会卡死。

## 七、怎么讲故事（从《仙逆》通读第1、4章提炼，比任何指标都重要）

**光调句长没用。仙逆和我的稿子最大的差别是结构。**

| 仙逆怎么做 | 具体 | 拙火之前错在哪 |
|---|---|---|
| **一章只有一件事** | 第4章整章只写"爬石阶→剑灵阁测试"，失败两次 | 一章塞了六件事：废窑/缺口碗/货郎/白瓷瓶/找陈三/锔碗换粮，每件写一半 |
| **配角来一刀就走** | 中年人路过给一句"毅力绝佳，可惜资质太过普通，无缘"，然后走人；青年只说"不合格，下一个" | 货郎/爹/娘/陈三/陈禾各有 2-4 轮完整对话，还展开身世 |
| **用时间跳跃推进** | "走了不到半天"→"两天后"→"第二天夜晚"→"第三天日出"→"三天后" | 全程线性流水，从黄昏写到第二天傍晚 |
| **情绪写在身体上** | "血泡里钻心的刺痛""膝盖，脚指血肉模糊""衣服已经被血液浸透" | 直接写"他很难过""心里发闷" |
| **不展开配角内心** | 中年人想什么只给一句"面色蜡黄"，不解释 | 每个配角都配一段身世背景 |
| **不解释设定** | 不说恒岳派是什么、剑灵是什么，读者从对话和行为里自己拼 | 大量科普式旁白 |
| **章末落在未兑现的动作** | "不合格，下一个。"——同一种失败的重复 | 宣言式结尾："我一定会走到最高处" |
| **计划粒度要细** | 一章 55-68 段小节拍（每段 45-60 字），一章 12-18 场次 × 3-6 秒 | 我的计划只有 9 个场次 × 8 秒，太粗 |

**所以写章前的第一个动作不是写正文，是问：这章的一件事是什么？写一句"主线：xxx"。**
写不出这一句，说明这章还没想清楚，别动笔。

**主角第一反应是退**：仙逆里王林所有选择都是"怎么活下去"，不是"怎么打赢"。
## 八、"全是对白"的真正原因（用户第二次退回才发现）

用户看稿子说"基本全是对白，没有对白是不是就不会写"。查下来**不是对白多**：

| | 纯叙述段 | 叙述占字数 | 观感 |
|---|---|---|---|
| 我的旧稿 | 25 段 / 1182 字 | 48% | 像全是对白 |
| 仙逆第4章 | 25 段 / 1307 字 | 64% | 叙述在干活 |
| 仙逆第1章（饭桌戏） | 43 段 / 2095 字 | 39% | 对白确实多，但不闷 |

对白段率 35-40% 跟参照书是一样的（36.4%）。**真正的问题是我的叙述段是空的**：
25 段里有 13 段是"他把火钳放下""他又捡起""拍了拍手上的黑"这种
**只写动作、不改变任何状态**的废段。读者一读就是"动作→对白→动作→对白"，
自然像对白连着走。

**修法（已写进 PROSE_SYS 和审稿器）**：

1. 每一段叙述必须改变一个状态：**物理**（泡破了、柴少了、灰被烧黑了）、
   **时间**（天黑了、两天后）、**空间**（走到坡底）、**认知**（他忽然想明白了）、
   **他人**（他爹停下了手）。动作本身不是终点，**动作造成的变化才是**。
2. 禁止"拿起—放下—又拿起"这种无信息动作循环。
3. 相邻两段不许重复同一个动作。
4. 每个场次 **两段叙述 + 一段对白**，叙述要比对白厚。
5. 审稿器会自动抓：空叙述段（≤24 字、只有动作、没有任何状态量词）、
   相邻叙述段重复动作。

**写完自检一句话**：这段过去之后，什么变了？什么都没变就删掉重写。
## 九、文体模型（tools/novel/style_model.py 的实测结果，仙逆40章 vs 凡人40章 vs 我的稿）

**别再凭感觉判断"像不像"。这些数字是标尺：**

| 特征 | 仙逆 | 凡人 | 我的(旧稿) | 目标 |
|---|---|---|---|---|
| 动作动词/千字 | 6.15 | 5.00 | **18.94** | 6-9 |
| 对白叙述交替% | 30.9 | 32.2 | **71.5** | 30-35 |
| 对白轮均段 | 1.50 | 2.39 | **1.07** | 1.5-2.4 |
| 连接词/千字 | 9.21 | 11.90 | **2.12** | 8-12 |
| 身体部位/千字 | 12.6 | 12.3 | **30.5** | 12-16 |
| 比喻/千字 | 1.56 | 1.29 | **5.00** | 1.3-2.0 |
| 叙述具体物/段 | 0.38 | 0.48 | **2.15** | 0.4-0.7 |
| 感官·味嗅/千字 | 3.33 | 3.16 | **1.98** | 3.0-4.0 |
| 逗号/句号 | 6.49 | 2.34 | 2.84 | 3.0-6.5 |
| 章末含对白 | 33% | 42% | **0%** | 30-40% |
| 心理直述/千字 | **1.21** | 3.01 | 1.49 | ≤1.5（仙逆几乎不直说情绪） |

**从数字里读出来的三条手艺**：

1. **动作动词 3 倍 = 动作分解**。仙逆的动作是**一次性的、有后果的**
   （"他爬过的石阶，留下一道深深的血迹"）；我的是**分解的、无后果的**
   （"他把手收回来""他拍了拍手上的黑"）。改法：一个动作一次写完，
   写完就换状态，不要把一个动作拆成三段。
2. **交替率 2.3 倍 = 节奏碎**。我段段在叙述和对白之间切，像剪辑过的。
   仙逆是**大段叙述把对白包住**：先写三五段叙述，再来一句对白。
   改法：连续两三段叙述 → 一句对白 → 再两三段叙述。
3. **连接词 1/4 = 段落之间只是并置，没有逻辑**。
   改法：每两段之间至少用一次"可/但/只是/于是/然而/所以"把因果递进挑明。

另外三条：**身体词和比喻都减半**（我是在堆）；**叙述段的具体物从 2.15 降到 0.5**
（我的叙述段像物品清单，参照书是点缀）；**章末用对白收尾**（参照书 33-42%，
我 0%）。

**跑一遍就知道差多少**：
```bash
python tools/novel/style_model.py --book 仙逆 --n 40
python tools/novel/style_model.py --mine 我的第1章.md 我的第2章.md
```
## 十、《仙逆》的五条具体手法（从原文读出来的，不是指标）

**必须比对手：拿仙逆的"安静章"（前 8 章）比，不要拿全书平均比。**
仙逆全书样本里大量打斗戏，动作密度天生高；你的章节如果是文戏，
该对标的是它开篇的文戏章（43 段 × 51 字/段、动作词 9.97、比喻 0.72）。

### ① 一行就是一段，段内 2–4 句
这些 .txt 里**换行即分段**，段内 45–60 字。
写"一句一段"是诗，不是网文。段数参照书是 43–65 段/章。

### ② 动作提示和台词在同一行，**动作在前**
> 王林目光冰冷，缓缓说道："谁，向我下了战书，出来！"

我以前写成 `"这窑还能烧。"他对着空窑说…`（台词在前、动作在后），
结果对白段落都很短、每段字数上不去。**把台词移到行尾、动作提到行首**。

### ③ 对白长短混合，不是全都短也不是全都长
参照书：37% 在 10 字以内、38% 超过 25 字。
短的当反问/命令/感叹（"破！""问。""你困了。"），
长的让角色把一件完整的事说透（"我娘死的早，要不是二娘小时候照顾我…"）。
**中位 16–21 字。**

### ④ 心理直述只用来写配角
仙逆写配角："灰衣老者内心苦涩，暗叹不已。"
**主角的心理一律用动作带过**——这是它情绪不显的关键。
（所以"心理直述"密度要 ≤1.5/千字，不是越高越好。）

### ⑤ 叙述段要改变状态，不是描述画面
参照书："他爬过的石阶，留下一道深深的血迹。"——状态变了。
我以前写"他把手收回来""他拍了拍手上的黑"——什么都没变。
自检：**这段过去之后，什么变了？**

## 十一、怎么把达成率从 60% 推到 80%（实测有效的手法）

1. **先机械后手改**：
   - 机械：合并叙述行到 45–60 字、把台词移进行尾、砍掉 80% 的比喻
   - 手改：砍日常动作词、砍身体部位词、砍具体物堆砌、给并列叙述加连接词
2. **一次只改一项**。给 8 条反馈，模型只改得动 1–2 条，必然横跳。
3. **LLM 整章重写改不动这些**，它每次都回到自己的默认写法。
   真正见效的是：**agent 自己按尺子逐句改**（我手写那一稿，达成率从 53.7% → 66.4%）。
4. **指标要同场景对标**：文戏对文戏，打斗对打斗。

```bash
python tools/novel/gap_report.py --mine 我的稿.md    # 逐项达成率 + 未达标项排序
```
## 十二、对白模式库（写对白前先查这张表）

完整库在 `manga/渺渺仙途/00_素材/对白模式库_九种.md`（含九种模式的拙火样例），
仙逆对应原文摘录在同目录 `对照样例_仙逆原文.md`。

| # | 模式 | 这场戏的对白要完成什么 | 关键手法 |
|---|---|---|---|
| 1 | 家常带压 | 表面寒暄，底下有压力 | 全是家常话，压力靠"不回应"和沉默传递 |
| 2 | 陌生人试探 | 双方都藏着身份 | 一方说谎（"唤我大牛便是"），另一方看穿但不点破 |
| 3 | 选择式铺陈 | 买卖/谈判 | 卖方把选项摊开（这样那样这样），买方只要一样 |
| 4 | 位置定局 | 一方说了算 | 说完就定，没人反驳，因为位置在那儿 |
| 5 | 条件摆清自己选 | 让对方自己挑 | 好处坏处都说明白，结尾是"你挑" |
| 6 | 先要好处 | 想办事先谈价 | "解了惑有什么好处"——先要价再开口 |
| 7 | 暴怒极短句 | 情绪爆发 | 句子短到只剩骨头，动词都砍掉 |
| 8 | 群像短促惊呼 | 群体反应 | 一群人各喊一句，不解释不展开 |
| 9 | 先共情再提要求 | 说服对方 | 先承认对方（"老夫很敬佩你的忍耐"），再提条件，再给承诺 |

**库在** `manga/渺渺仙途/00_素材/对白模式库_九种.md`（九种模式各带样例），
仙逆对应摘录在同目录 `对照样例_仙逆原文.md`。
库已实测对齐：每段字数 52.5（仙逆 52.3）、身体词 12.39（12.6）、比喻 0.89（1.56）、短台词占比 35.5%（37.6%）。

**三条硬规则**：
1. **每句台词前带动作提示**——仙逆几乎没有光秃秃的台词行，一行 40–60 字
   （"父亲…对推门进来的铁柱说道：'铁柱，书读的怎么样了？'"）。
   **光秃秃的台词行是对白流水的主要来源。**
2. **一行就是一段，段内 2–4 句，45–60 字**。
3. **台词是武器不是信息交换**：每句至少做一件事——
   揭穿/施压/拒绝/翻转/给新信息/沉默。复述读者已知的事一句都不留。
## 十三、最贵的一课：**对标要同场景，不能用全书平均**

我按《仙逆》**全书平均**调了 35 轮，始终差一半多。后来改用**仙逆第 1 章**
（同类型：家常章）当标尺，数字完全不同：

| | 台词中位 | ≤10字 | >25字 | 每段字数 | 动作词 | 身体词 | 比喻 | 连接词 |
|---|---|---|---|---|---|---|---|---|
| 仙逆**全书平均** | 16 | 37.6% | 37.8% | 52.3 | 6.15 | 12.6 | 1.56 | 9.21 |
| **仙逆第1章**（该对标这个） | **26** | **14%** | — | **46.3** | **9.4** | **8.7** | **0** | **7.2** |

**"按全书平均把台词往短里压"是错的**——仙逆第1章台词中位 26 字、比喻一个都没有。
差一半多不是能力问题，是**尺子拿错了**，所以怎么调都不收敛。

**规矩**：
1. 找**同类型**的参照章（家常章对家常章，打斗章对打斗章），不要用全书平均。
2. 标尺一旦定死就别再动；换标尺前先问"这章该像哪一章"。
3. **写的时候旁边要有样本，不是指标清单**。指标是事后的尺子，样本是当下的模具。
   对着仙逆那一段仿写，一次就中（台词 4 句/中位 15/最长 17 vs 仙逆 4/16/17）；
   只给指标清单，35 轮横跳在 53–66%。
## 十四、最后一条，也是最根本的一条：**场次计划的粒度决定正文的粒度**

第 01 章我写砸了十几版，最后才想明白：

- 仙逆第 1 章：**100 段**，每个段落承载一个完整的意思
- 我的场次计划：**9 个场次**（"每场一个动作"），9 个节拍写不出 100 段
  → 一个节拍硬撑 10 段，段落就必然薄、就必然靠对白撑节奏
  → 读起来就是"对话式的多、每段都很短"

**所以**：场次计划不能停在"场次"级别，要落到**节拍**级别——
一场戏拆成 8–12 个节拍，每个节拍 = 一个意思 = 一段。

实测：按节拍重排后，同一个故事从 2700 字 / 57 段变成 4496 字 / 95 段，
每段 37 字（仙逆 46）。**剩下的差距全在段落内部的密度，不在结构了。**

**流程改成**：
1. 场次计划（宏观，一句话一件事）
2. **节拍表**（每场 8–12 个节拍，每个节拍一个完整意思）
3. 正文（一个节拍写 1–2 段，每段 45–60 字）

跳过第 2 步直接写正文 = 段落必碎。这是我这一整轮最大的教训。
